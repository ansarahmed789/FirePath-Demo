# FirePath Demo

A clickable prototype of FirePath, a wildfire map app for Saskatchewan. Open the link on a phone or computer. Nothing to install.

**Live demo:** https://ansarahmed789.github.io/FirePath-Demo/

- Tap anywhere on the map to see how a fire could spread over 1, 2 and 4 hours.
- Try the What-If tab (wind speed, temperature, dryness, and a compass for wind direction).
- Create an account to save places and see alerts. Accounts stay in your own browser.

**This is a student prototype.** All fire, weather, danger and alert numbers are sample data, not real conditions. FirePath is not an evacuation tool. For official information see [SaskAlert](https://www.saskalert.ca) and the [SPSA](https://www.saskpublicsafety.ca).

This repository only holds the built website. The team's source code and documents are kept elsewhere.
